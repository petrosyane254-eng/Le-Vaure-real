# LE VAURÉ V3 — Home merchandising rebuild

This version keeps the existing Django API integration and internal pages from V2, while rebuilding the homepage around a premium category/campaign merchandising rhythm inspired by large outdoor/fashion storefronts.

Key points:
- Existing `/backend-api/*` integration remains intact.
- Django Admin products feed Featured/Latest product sections.
- Django home hero/promo/editorial/collections are used when available.
- Local fallback content prevents an empty homepage.
- Responsive desktop/tablet/mobile layout.
